# voice-evals

Claude-Code-Skill: fonio Voice-Agent-Prompts gegen ein Eval-Set messen und verbessern.

- `SKILL.md` — die beiden Aufgaben: Fälle schreiben, Runde auswerten
- `references/regeln.md` — Prompt-Audit, Fehler-Taxonomie, Ursachenanalyse

Methodik und Betrieb stehen nicht hier, sondern in `aalbeek-ops`: [playbooks/evals.md](https://github.com/aalbeek-ai/aalbeek-ops/blob/main/playbooks/evals.md) und [sops/voice-agent-evals.md](https://github.com/aalbeek-ai/aalbeek-ops/blob/main/sops/voice-agent-evals.md).

## Installation

Dieses Repo **ist** das Skill-Verzeichnis. Klonen nach `~/.claude/skills/voice-evals`, mehr nicht.

```
git clone git@github.com:aalbeek-ai/voice-evals.git ~/.claude/skills/voice-evals
```
